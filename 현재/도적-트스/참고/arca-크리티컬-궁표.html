크리티컬 관련 메커니즘 정보가 챈에 없는 것 같길래 작성해 보니 참고 바람. 

메랜이 아니라 옛메라고 한 이유는 메랜에서 달라진 점이 있는지 100% 확신은 못 하기 때문에 그런 거. 아마 그대로 넘어왔지 않았나 싶긴 함.


<바쁜 자들을 위한 선 요약>

1. 이 글은 순수하게 스킬 퍼댐의 기댓값만을 논한 것이고, 실제 몹에게 들어가는 딜 계산은 훨씬 복잡하고 변수가 많다. 특정 몹 사냥시 자신의 딜에 대한 정확한 가늠이 필요하다면 그냥 계산기를 돌리자.

2. 옛메의 크리티컬은 기본적으로 곱연산이 아니라 합연산이다. 따라서 스킬 퍼댐의 합이 같더라도 타수가 많은 쪽이 무적권 유리하다. 애블보다 덥샷이 더 좋다는게 다 이유가 있다.

3. 샾 30렙은 대충 궁수/표도의 딜 기댓값을 약 1.5배 정도 증폭시키는 씹사기스킬이다.

4. 샾은 1렙도 개사기니까 120에 갓 4차 찍은 궁수들은 딴 스킬 다 좆까세요 하고 샾 3렙부터 찍어서 지속시간 30초를 확보하자.

5. 궁표 외 기본 크리 없는 직업의 샾30 기준 딜 기댓값은 대략 1.05~1.1배 정도이다.



1. 기본 크리티컬

1.1. 궁수/표도의 기본적인 딜 기댓값

우선 궁수와 표도의 크리티컬 계산 방식은 완벽하게 똑같고, 단지 크리 확률 자체만 다르다.

스킬 설명은 표도는 '50% 확률로 200% 대미지'. 궁수는 '40% 확률로 200% 대미지' 라고 적혀있는데, 설명을 개 좆같이도 해놨음. 

아주 정확하게 표현하자면, 

표도는 '50% 확률로 타격당 100%p 대미지 추가', 궁수는 '40% 확률로 타격당 100%p 대미지 추가' 

가 맞음. 그러니까 뭐 곱하기 2, 더하기 200% 이런식으로 계산하면 안 됨.


따라서, 대미지 기댓값을 계산하는 방법은 아래 수식을 따름.

대미지 기댓값 (%) = {(스킬 1타 당 대미지)+(크리 확률)*100}*(스킬 타수)


위 수식을 전개하면,

대미지 기댓값 (%) = (스킬 1타 당 대미지)*(스킬 타수)+(크리 확률)*100*(스킬 타수)


여기서 (스킬 1타 당 대미지)*(스킬 타수) 는 그냥 스킬 자체의 기본 총 대미지이고, 궁표의 크리 확률인 40%=0.4, 50%=0.5를 각각 대입하면,


궁수 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+40*(스킬 타수)

표도 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+50*(스킬 타수)

(*) 표도 같은 경우, 쉐파를 켰다면 그냥 최종 결과에 1.5를 추가로 곱하면 됨


결론적으로 크리티컬의 딜 기여도는 스킬 타수에 비례한다는 것을 알 수 있다.


(*) 예외

설명을 좆같이 적어논 거도 모자라서 이 계산방식에 예외 사례가 딱 하나 있음. 바로 헌터의 애로우 봄.

얘는 괴상하게도 진짜로 크리댐이 2배로 적용됨. 그래서 애로우 봄은 위 수식을 쓰면 안되고, 그냥 기본 대미지에 1.4를 곱해줘야 딜 기댓값이 나옴.


1.2. 궁수/표도의 스킬별 딜 기댓값

위에서 계산식을 알았으니, 이제 스킬별 기댓값을 구해볼 수 있다. 당연히 크리 포함 모든 스킬은 만렙이라는 전제로 계산하였음.


* 궁수 스킬 퍼댐 기댓값

< 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+40*(스킬 타수) >

- 에로우블로우 : 260+40*1 = 300%

- 더블샷 : 260+40*2 = 340%

- 아이언에로우 : 180+40*1 = 220% (첫 타격 기준, 두번째 타격 이후는 0.9^(n-1) 곱해주면 됨. *n=타격한 몹 수)

- 에로우 봄 : 130*1.4 = 182%

- 에로우 레인/이럽션 : 160+40*1 = 200%

- 파이어 샷 : 150+40*1 = 190% (무속성 기준, 속성 추댐 적용 방식은 내가 잘 모르겠음)

- 스트레이프 : 400+40*4 = 560%

- 폭풍의 시 : 100+40*1 = 140%

(*) 폭시는 스트 대비 약 1.5배 정도의 DPS를 가짐. 정확히는 폭시가 분당 500타 공격하고, 스트는 보통 공속 활/석궁 부스터 사용 기준 분당 83회=332타 공격하므로 500/332=1.5. 

따라서 신궁과 보마의 DPS는 1.5배 차이지만, 실제로는 석궁/활 무기상수 차이와 힘스탯 요구치, 스나이핑 사용 등을 고려하면 1.5배보다는 차이가 약간 적다고 보면 됨


* 표도 스킬 퍼댐 기댓값

< 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+50*(스킬 타수) >

- 럭키 세븐 : 300+50*2 = 400% / 쉐파 사용 시 400*1.5 = 600%

- 드레인 : 160+50*1 = 210% / 쉐파 사용 시 210*1.5 = 315%

- 어벤저 : 180+50*1 = 230% / 쉐파 사용 시 230*1.5 = 345%

- 트리플 스로우 : 450+50*3 = 600% / 쉐파 사용 시 600*1.5 = 900%

(*) 럭세 같은 경우에는 딜 공식 자체에 럭이 개입되는 특수한 형태라 실제 나오는 딜은 퍼댐 자체보다 훨씬 강함. 그러니까 드레인/어벤 퍼댐 100%하고 럭세 퍼댐 100%를 같다고 보면 안된다는 뜻임. 

궁수가 스공으로 표도 개바르는데 막상 붙으면 처발리는게 공속이나 얻어맞을때 딜 끊기는거 유무도 크지만, 그냥 단순히 고렙이 될수록 럭 추댐 때문에 럭세가 더 쌔져서 그런것도 주요함. 럭세 딜은 단순히 600%로 계산되는 게 절대로 아니니까, 이거 보고 스트하고 럭세 딜이 40%p밖에 차이 안나는데 궁수가 스공 훨씬 높으니 표도보다 쌔네? 이런 착각은 하지 않길 바람.

참고로 트스도 럭세와 완벽하게 똑같은 딜 계산식을 따르고, 나머지 스킬은 궁수와 마찬가지로 그냥 퍼댐 자체만 보면 됨.



2. 샤프 아이즈 + 기본 크리티컬

2.1. 샾 기준 궁수/표도의 기본적인 딜 기댓값

궁수 4차 스킬인 샤프 아이즈는 기본 크리티컬을 보유한 궁수/표도의 딜을 미친듯이 늘려주는데, 3차까지 메인 보스딜러로서 약간 애매했던 궁수/표도를 순식간에 메인 딜러 포지션에 올려놓은 씹사기스킬이다. 실제 효과가 어느 정도인지 알아보자.

샤프 아이즈의 스킬 설명도 크리티컬과 동일하게 개 좆같이 적혀있는데, 30렙 기준 '크리티컬 확률 15%, 대미지 +40%' 라고 한다.

좆까지 말라하고 아주 정확하게 표현하자면, 

표도는 '(50+15)% 확률로 타격당 (100+140)%p 대미지 추가', 궁수는 '(40+15)% 확률로 타격당 (100+140)%p 대미지 추가' 

가 맞음.

이제 앞서 한 것과 동일하게 계산해 보자.


샾 기준 대미지 기댓값 (%) = {(스킬 1타 당 대미지)+(크리 확률)*(100+140)}*(스킬 타수)


위 수식을 전개하면,

대미지 기댓값 (%) = (스킬 1타 당 대미지)*(스킬 타수)+(크리 확률)*240*(스킬 타수)


여기서 (스킬 1타 당 대미지)*(스킬 타수) 는 그냥 스킬 자체의 기본 총 대미지이고, 샾 기준 궁표의 크리 확률인 55%=0.55, 65%=0.65를 각각 대입하면,


샾30 기준 궁수 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+132*(스킬 타수)

샾30 기준 표도 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+156*(스킬 타수)

(*) 표도 같은 경우, 쉐파를 켰다면 그냥 최종 결과에 1.5를 추가로 곱하면 됨


마찬가지로 샾이 있든 없든 크리티컬의 딜 기여도는 스킬 타수에 비례한다는 것을 알 수 있다.


2.2. 샾30 기준 궁수/표도의 스킬별 딜 기댓값

* 궁수 스킬 퍼댐 기댓값

< 샾30 기준 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+132*(스킬 타수) >

- 에로우블로우 : 260+132*1 = 392% (노샾 대비 1.31배)

- 더블샷 : 260+132*2 = 524% (노샾 대비 1.54배)

- 아이언에로우 : 180+132*1 = 312% (노샾 대비 1.42배, 첫 타격 기준, 두번째 타격 이후는 0.9^(n-1) 곱해주면 됨. *n=타격한 몹 수)

- 에로우 봄 : 130+0.55*(130+140) = 278.5% (노샾 대비 1.53배, 오류 가능성 있음. 봄 샾 적용 계산식은 확실하게 기억이 안남)

- 에로우 레인/이럽션 : 160+132*1 = 292% (노샾 대비 1.46배)

- 파이어 샷 : 150+132*1 = 282% (노샾 대비 1.48배, 무속성 기준, 속성 추댐 적용 방식은 내가 잘 모르겠음)

- 스트레이프 : 400+132*4 = 928% (노샾 대비 1.66배)

- 폭풍의 시 : 100+132*1 = 232% (노샾 대비 1.66배)

(*) 폭시와 스트의 DPS 차이에 대해서는 앞의 내용 참고. 


* 표도 스킬 퍼댐 기댓값

< 샾 기준 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+156*(스킬 타수) >

- 럭키 세븐 : 300+156*2 = 612% / 쉐파 사용 시 612*1.5 = 918% (노샾 대비 1.53배)

- 드레인 : 160+156*1 = 316% / 쉐파 사용 시 316*1.5 = 474% (노샾 대비 1.50배)

- 어벤저 : 180+156*1 = 336% / 쉐파 사용 시 336*1.5 = 504% (노샾 대비 1.46배)

- 트리플 스로우 : 450+156*3 = 918% / 쉐파 사용 시 918*1.5 = 1377% (노샾 대비 1.53배)

(*) 럭세/트스의 특이성에 대해서는 앞의 내용 참고


그러니까 궁수/표도 기준, 샾30은 딜 기댓값을 대충 1.5배 정도 증폭시켜준다고 생각해도 된다.

왜 표도가 샾에 목숨을 거는지, 샾이 뭐길래 4차 궁수 없음 보스전이 성립이 안되는지 이제 알았으리라 믿는다.



* TMI (1)

위의 계산은 30렙 샾 기준인데, "돈 없어서 어차피 샾 만렙 못 찍는데 샾 나중에 찍어도 되나요?" 라는 물음이 나올 수 있는데,

결론부터 말하면 "지랄하지 말고 샾 10렙이나 찍어라" 가 답이다.


앞에서

표도는 '(50+15)% 확률로 타격당 (100+140)%p 대미지 추가', 궁수는 '(40+15)% 확률로 타격당 (100+140)%p 대미지 추가'

라고 했고, 기본적인 샾 스킬 설명은 '크리티컬 확률 xx%, 대미지 +yy%' 로 되어 있다.

위의 정확한 표현을 샾 n렙 기준으로 다시 적으면,

표도는 '(50+xx)% 확률로 타격당 (100+(100+yy))%p 대미지 추가', 궁수는 '(40+xx)% 확률로 타격당 (100+(100+yy))%p 대미지 추가'

가 일반화된 표현이다.

이걸 가지고 1렙 샾의 효율을 알아보자. 1렙 샾의 경우 '크리티컬 확률 1%, 대미지 +11%' 이므로,

궁수는 '(40+1)% 확률로 타격당 (100+(100+11))%p 대미지 추가'

가 되겠다. (1렙 샾을 표도한테 줄 일이 있나 싶어 궁수만 계산하겠음. 궁금하면 직접 계산해봐라)


위에서 한 방식대로 똑같이 계산하면,


대미지 기댓값 (%) = (스킬 1타 당 대미지)*(스킬 타수)+(크리 확률)*211*(스킬 타수)


여기서 (스킬 1타 당 대미지)*(스킬 타수) 는 그냥 스킬 자체의 기본 총 대미지이고, 샾 1렙 기준 궁수의 크리 확률인 41%=0.41을 대입하면,


1렙 샾 기준 궁수 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+86.51*(스킬 타수)


< 1렙 샾 기준 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+86.51*(스킬 타수) >

- 에로우블로우 : 260+86.51*2 = 346.51% (노샾 대비 1.16배)

- 더블샷 : 260+86.51*2 = 433.02% (노샾 대비 1.27배)

- 아이언에로우 : 180+86.51*1 = 266.51% (노샾 대비 1.21배, 첫 타격 기준, 두번째 타격 이후는 0.9^(n-1) 곱해주면 됨. *n=타격한 몹 수)

- 에로우 봄 : 130+0.41*(130+111) = 228.81% (노샾 대비 1.26배, 오류 가능성 있음. 봄 샾 적용 계산식은 확실하게 기억이 안남)

- 에로우 레인/이럽션 : 160+86.51*1 = 246.51% (노샾 대비 1.23배)

- 스트레이프 : 400+86.51*4 = 746.04% (노샾 대비 1.33배)

- 폭풍의 시 : 100+86.51*1 = 186.51% (노샾 대비 1.33배)


단 1렙만으로도 1.2~1.3배 딜뻥이 되는 미친 좆사기스킬인데 지속이 1렙당 10초씩밖에 안 되는게 난점이다.

그러니까 120렙에 막 전직했으면 딴 스킬 찍고싶은거 많겠지만 다 좆까라하고 샾 3개를 일단 찍어서 지속시간 30초를 확보하고 시작하는 것이 옳다. 폭시, 펄스, 프리저 이런것들 찍어보고 싶겠지만 121렙까진 좀 참아라.



* TMI (2)

크리티컬까지 고려해야 되는 궁표 유저라면 이런 고민을 해 본 적이 있을 것이다.

'럭세20하고 트스1렙하고 뭐가 더 쌔지?', '스트1렙하고 더블샷20하고 뭐가 더 쌔지?'


그래서 몇 가지 경우에 대해 기댓값을 나열했다. 혹시 여기 없는 게 있다면 위에 계산해놓은거 직접 비교하든가 아님 한번 계산해봐라. 이제 할 줄 알잖아?


- 럭세 vs 어벤 : 400% vs 230% -> 2마리만 되도 어벤이 더 쌔다...라고 생각하면 앞에 제대로 안 읽은거다. 럭세/트스의 100%는 타 스킬의 100%하고 다르다고 했음. 캐릭 스펙 따라 달라지겠지만 사실상 2마리까진 럭세가 더 쌔다고 보는 게 맞다. 어벤은 3마리부터 던져라.

- 스트레이프 1렙 vs 더블샷 : 368% vs 340% -> 항상 스트>더블샷

- 폭시 1렙 vs 스트 : 4*1.5*92%=552% vs 560% -> 1렙이면 스트>폭시

- (1렙 샾) 폭시 1렙 vs 스트 : 4*1.5*138.51%=831.06% vs 746.04% -> 샾 있으면 항상 폭시>스트

- 트스 1렙 vs 럭세 : 456% vs 400% -> 항상 트스>럭세



* TMI (3)

크리 없는 애들은 어떤가요? 라는 물음도 나올 수 있는데, 사실 난 원딜충이라 타 직업의 샾 효율에 대해서는 앞에처럼 각 스킬별로 현란하게 계산은 못해준다.

다만 계산 방식 정도만 대충 알고있는데 오류 가능성이 있으니까 참고만 해라.


앞의 일반화된 계산 방식을 보자. 기본적인 샾 스킬 설명은 '크리티컬 확률 xx%, 대미지 +yy%' 로 되어 있다고 했고, 표도를 예로 들면

'(50+xx)% 확률로 타격당 (100+(100+yy))%p 대미지 추가'


여기서 기본 크리티컬로부터 참조된 50% 확률과 100% 대미지를 0으로 바꾸면 된다. 그러면,

'(xx)% 확률로 타격당 (100+yy)%p 대미지 추가'


이게 기본 크리티컬이 없는 물리직업의 샾 대미지 계산 공식이다. 만약 샾이 30렙이라면, 

'15% 확률로 타격당 140%p 대미지 추가'

가 되겠다. 따라서, 궁표 외 타 물리직업의 샾30 대미지 기댓값은


대미지 기댓값 (%) = (스킬 1타 당 대미지)*(스킬 타수)+0.15*140*(스킬 타수)


가 되고 결과적으로 다음과 같다.


30렙 샾 기준 타 직업 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+21*(스킬 타수)


이 효율은 직업마다 다른데, 대충 1.05~1.1배 딜뻥으로 보면 된다고 알려져 있다.

예를 들면, 메랜에는 없지만 해적 직업군의 캡틴을 보자. 캡틴의 주력기는 배틀쉽 캐논인데, 이건 380% 대미지를 4번 주는 스킬로, 기본딜은 총 1520% 이다.

샾 기댓값 계산을 해 보면,


< 30렙 샾 기준 타 직업 대미지 기댓값 (%) = (스킬의 기본 총 대미지)+21*(스킬 타수) >

- 배틀쉽 캐논 : 1520+21*4 = 1604% (노샾 대비 1.055배)


대충 1.055배 딜뻥 효과가 있고, 표도처럼 샾에 연연할 필요가 딱히 없다는 것을 알 수 있다. 

오해를 피하기 위해 첨언하자면, 파티버프 1개가 DPS를 1.05~1.1배 올려주는건 상당히 좋은 효과가 맞다. 당장 공격력과 주스탯을 1.05~1.1배 더 준다고 생각해봐라.

단 이건 딜 1이라도 모조리 누적되는 보스전에서나 좋은 거고, 필드사냥을 하는 경우에는 크리 확률이 너무 낮아 방수 예측이 전혀 안 되기 때문에 실질적으로 체감은 거의 없다고 봐도 된다. 필드사냥 할 때 표도 외 직업은 궁수 없다고 크게 불편해할 필요성이 없다는 이야기다. 

몹이 존나게 쌔서 한 20대 때려야 죽일 수 있으면 평균회귀를 기대해볼만 하니 괜찮을수도 있는데, 그럴 일이 있겠냐고


참고로 마법사의 경우 샾30은 그냥 15% 확률로 대미지 1.4배 딜뻥이고, 따라서 그냥 1.06배 딜뻥으로 보면 된다. 물리직업과는 달리 진짜로 곱연산이라, 스킬 마릿수나 타격 횟수에 관계없이 모든 스킬의 딜뻥 기댓값이 1.06배로 일정하다.

보스전 외에는 위의 단점 다 공유하니까, 마찬가지로 필드사냥 할 때 크게 신경쓸 필요 없음.

마법사가 샾 효율이 딱히 좋은 것도 아닌데 스킬 설명에 그나마 제일 잘 맞게 적용이 되는 걸 보면, 옛메 스킬 설명 적은 새끼는 회사에서 면상에 보고서 많이 맞아봤을 것 같다.
