## 4. 공식 (확정)

### 4.1 스탯 풀합산 모델

```
Total LUK = floor((기본LUK + Σ장비 깡LUK + 무기 LUK) × (1 + (ΣLUK% + Σ올스탯%) / 100))
Total DEX = floor((기본DEX + Σ장비 깡DEX + 무기 DEX) × (1 + (ΣDEX% + Σ올스탯%) / 100))
```

- **올스탯%는 LUK%/DEX% 양쪽 풀에 모두 합산** (게임 공식)
- 모든 잠재는 **풀합산 후 한 번에 곱** (per-item 아님)
- `floor`(소수점 버림) 적용

### 4.2 무기공격력 (WA)

```
WA = floor(무기깡공 × (1 + 공%/100)) + 표창공 + 장갑공 + 혼테일(+30)
```

- **공%는 무기 깡공에만 적용** (표창/장갑은 별도 가산)
- 혼테일 버프 = 무기공 +30 (체크 시)
- floor 는 weapon × (1+공%) 단계에서만

### 4.3 스공 (스탯 공격력, 일반 공격력 MAX)

도적 표창 / 단검 공식 (Nise's Formula 기준):

```
스공 = floor((LUK × 3.6 + DEX) × WA / 100)
```

→ 이 값이 PlanetCompare 같은 사이트의 "스공" 표시값.

### 4.5 LS/TT 데미지 공식 (특수 공식 적용)

도적 표창 (Lucky Seven / Triple Throw) 은 **일반 공격력 공식이 아닌 LUK 특수 공식** 사용:

```
per hit MAX = LUK × 5.0  × WA / 100 × (스킬데미지% / 100)
per hit MIN = LUK × 2.5  × WA / 100 × (스킬데미지% / 100)
```

- 출처: [Nise's Formula Compilation](https://forum.legends.ml/index.php?threads/nises-formula-compilation.36234/), [arca 크리티컬 글](https://arca.live/b/mapleland/114593305)
- **표창 마스터리 미적용** (LS/TT 는 LUK 5/2.5 자체 변동으로 ×2 MIN/MAX)
- 일반 공식 (LUK × 3.6) 보다 LUK 영향력 큼 → 같은 LUK 일 때 약 1.39배

**크리 적용**:
- 크리스로우 Lv L: 크확 `20+L`%, per crit `10+3L`%p
- 샤프 (외부 버프):
  - 쓸샾 (10%/+15%) → per crit 추가 = (100 + 15) = +115%p
  - 만렙 (15%/+40%) → per crit 추가 = (100 + 40) = +140%p
- crit hit = base hit × (1 + per_crit / 100)

**전체 사이클 (3타 또는 2타)**:
```
cycleMult = hits × (1 + 쉐파_스킬데미지%/100) × (1 + 총뎀%/100) × (보스전 ? 1 + 보공%/100 : 1)

크리 ✗ MIN = perHitMin × cycleMult
크리 ✗ MAX = perHitMax × cycleMult
크리 ✓ MIN = perHitMin × (1 + perCrit/100) × cycleMult
크리 ✓ MAX = perHitMax × (1 + perCrit/100) × cycleMult

기댓값 = ((1 - 크확/100) × (perHitMin+perHitMax)/2
       + (크확/100) × (perHitMin+perHitMax)/2 × (1+perCrit/100)) × cycleMult
```

**1타 데미지 (인게임 검증용)**:
```
oneHitMult = (1 + 총뎀%/100) × 보스배율   ← 쉐파/타수 제외
1타 일반 = perHitMin × oneHitMult ~ perHitMax × oneHitMult
1타 크리 = 위 × (1 + perCrit/100)
```

→ 인게임에서 트스 한 번 쓰면 1타 × 3개 데미지 숫자 뜸. 그게 이 범위 안에 들어와야 공식 검증.
→ 쉐파는 별도 데미지 숫자로 뜸 (분신).

### 4.6 잠재 / 버프 적용 순서

1. `perHitMax/MIN = LUK × 5/2.5 × WA / 100 × skillDmg%`  ← LS/TT 특수
2. `× (1 + perCrit/100)` if crit
3. `× hits` (트스 = 3, 럭세 = 2)
4. `× (1 + 쉐파 스킬데미지%/100)`
5. `× (1 + 총뎀%/100)`
6. `× (1 + 보공%/100)` if 보스전

### 4.7 ⚠️ 한계 — 메플플 검증 안 됨

- LUK × 5/2.5 상수: **본점 빅뱅 전 KMS / MapleLegends 표준**. 메플플도 동일한지 인게임 측정 필요
- 검증 방법: 트스 한 번 쓰고 1타 데미지가 1타 데미지 범위 (크리 X 일반) 안에 들어오는지 확인
- 안 맞으면 LUK 계수 조정 (5 → 5.4 or 다른 값)

### 4.5 마력% / 데미지% / 곱연산 vs 합연산

- **잠재 % 옵션 (공%, 총뎀%, 크확%, 보공%)**: 곱연산 (각자 1+x/100 형태로 곱해짐)
- **크리 (옛메)**: **합연산** — 크리 떴을 때 추가 데미지가 더해짐 (×2 아님)
- 메플플 데미지 옵션은 곱연산. 합연산은 경험치/메소 시너지만.

## 5. UI 구조

### 환산 탭 (좌측)
1. **캐릭터** (직업/레벨/순수 LUK/순수 DEX) — LUK ↔ DEX 자동 연동
2. **현재 장비** — 13개 슬롯 dropdown (저장된 아이템에서 선택)
3. **비교 프리셋** — 여러 슬롯 교체를 묶음으로 정의

### 환산 탭 (우측 사이드바)
1. **현재 결과** — 트스 데미지 (크리 X/O × 스공 MIN/MAX) + 기댓값
2. **비교 결과** — 프리셋별 데미지 + 변화율%
3. **스킬** — 크리티컬 스로우 / 쉐도우 파트너 / 표창 마스터리
4. **버프** — 샤프 (없음/쓸샾/만렙) / 혼테일 / 보스전
5. **총 스탯 통계** — 깡 LUK/DEX/공격력/잠재 합산 read-only

### 아이템 관리 탭
- 좌: 아이템 폼 (슬롯/이름/스탯) + 무기 전용 잠재 + 장갑 쓸샾 체크
- 우: 저장 아이템 리스트 (슬롯별 그룹화) + 편집/삭제
- 상단: "현재 상태를 기본값으로" + "데이터 리셋"

## 8. 트스 데미지 비교 — 잠재 우열

> ⚠️ 본 섹션의 절대 수치는 **이전 calc (일반 공식 스공 × 4.5)** 기준. LS/TT 특수 공식 적용 후엔 절대값 다름. **변화율% (비율) 은 거의 동일** — 잠재 비교는 그대로 유효.

샤프 만렙 + 혼테일 + 쉐파 always-on 가정:

| 잠재 | 데미지 변화 | 비고 |
|---|---|---|
| 총뎀 +9% | +9.0% | 가장 효율 좋음 (최종 곱연산) |
| 크확 +8% | +6.27% | 샤프 만렙일 때 per_crit 240%p 영향 |
| 공격력 +9% | +4.67% | 무기 깡공만 적용, 표창/장갑/혼테일 dilution |

샤프 무 환경:
- 공%9 vs 총뎀9% → **총뎀 4.1% 더 강함**
- 쓸샾 환경에선 크확8% 같이 잠재가 더 효율적일 수도

→ 결론: **총뎀% > 크확% > 공격력%** (대부분 환경에서 일관됨)
