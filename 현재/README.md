## 2. 핵심 공식 (검증 끝)

### 스탯창 표시 공식 (풀 합산 모델)

```
총 INT = (기본 INT + Σ 깡 INT) × (1 + Σ INT% / 100)
총 LUK = (기본 LUK + Σ 깡 LUK) × (1 + Σ LUK% / 100)
마력  = (총 INT + 깡 마력_무기) × (1 + 마력% / 100)
```

- 잠재 % 는 **모든 아이템 합산 후 한 번 곱연산** (per-item 아님)
- 마력은 INT 와 합쳐져서 표시됨 (메플플 특유)
- 검증: `(678 + 69) × 2.12 = 1583.64` ≈ 인게임 1583 ✓
- 검증: `(1583 + 124) × 1.15 = 1963.05` ≈ 인게임 1963 ✓
- 출처: [메플플 마갤 33949](https://gall.dcinside.com/mgallery/board/view/?id=mapleplanet&no=33949)

### 데미지 공식

```
DMG = ((마력²/1000 + 마력 × 0.9 × F) / 30 + INT/200) × 스킬BA × 원소 × (1 + 총뎀%/100) × amp
```

- `F = 1.0` → MAX 데미지
- `F = 마숙` (블자20 = 0.6) → MIN 데미지
- **변동폭 ≈ 13%** (단순 ×0.6 변동의 1.67배 ❌)
- **안정 1킬** = MIN ≥ HP (항상 1킬)
- **MAX 1킬** = MAX ≥ HP (가능성 시작, 안 쓰는 개념)
- 출처: 메랜 마갤 공식 모음 (`mapleland/829358`)

### 검증 데이터 (안정 1킬 임계)

| amp | 마력 임계 | MIN 식 결과 | 인게임 HP |
|---|---|---|---|
| 0 | 1965 | 134,150 | 133,000 ✓ |
| 1 | 1890 | 134,375 (×1.07) | 133,000 ✓ |
| 2 | 1867 | 134,089 (×1.09) | 133,000 ✓ |
| 3 | 1847 | 134,118 (×1.11) | 133,000 ✓ |

4개 임계점 모두 +1% 이내 fit. **추정 fudge factor 없음**.

## 3. 캐릭터 기본 스탯 모델

```
시작 (Lv1):          주스탯 13, 부스탯 4/4/4
레벨업 (Lv 2+):      +5 AP/레벨
3차 전직 (Lv 70):    +5 AP 자동 분배
4차 전직 (Lv 120):   +5 AP 자동 분배

총 AP at Lv L = 5×(L-1) + (L≥70 ? 5 : 0) + (L≥120 ? 5 : 0)
INT + LUK = 17 + 총 AP  (STR/DEX 4 고정 가정, 마법사 기준)
```

- 너 Lv135 마법사 검증: 13 + 670 + 5 + 5 = 693 (all-in) — 너 INT 678 + LUK 19 (15 AP LUK 분배)

- 블자만 너 실측 (Lv20 BA=520) 으로 정확 검증
- 나머지는 max 만 근거 있고 sub-max 는 단순 선형 근사
- 출처: maplekibun.tistory.com/829

### 앰플 (Amplification) 멀티플라이어

```
amp(0) = 1.00
amp(L≥1) = 1.05 + 0.02 × L
→ Lv20 = 1.45
```

- 너 실측 (Lv1=×1.07, Lv2=×1.09, Lv3=×1.11) 기반 선형 외삽
- maplekibun 표 (Lv20=×1.25) 와 충돌. **너 실측 우선**
- 추후 정확한 메플플 패치 데이터 확보하면 수정 필요

## 6. UI 구조

```
헤더 (오렌지 별 + "메이플 플래닛")
└─ 메인 탭: [스탯 입력] [데미지 계산]
    │
    ├─ 스탯 입력
    │   └─ Sub-tab: [간단] [부위별]
    │       ├─ 간단:    인게임 INT / LUK / 마력 / 무기 총뎀% 직접 입력
    │       └─ 부위별:  직업/레벨 → 자동채우기, 기본 INT/LUK (양방향 연동),
    │                   부위별 표 (무기 맨 위, 비무기 마/마%/총뎀 비활성화),
    │                   풀 합산, 인게임 검증
    │
    ├─ 데미지 계산
    │   ├─ ① 사냥터 / 몬스터 / 몬스터 HP / 원소상성
    │   ├─ ② 스킬 / 스킬 레벨 / 스킬 데미지 / 숙련도%
    │   └─ ③ 앰플(0~20) / 마력(auto) / 무기 총뎀%(auto)
    │   결과: 현재 데미지 (MIN ~ MAX, 1킬 여부), 안정 1킬 필요 마력 (vs 현재)
    │
    └─ Sidebar (항상 표시):
        총 INT / 총 LUK / 최종 마력 + (부위별 모드: debug breakdown 표시)
        + 전체 초기화 버튼
```
