# 메이플 플래닛 환산 주스탯 사이트 — 작업 이어받기

> 다른 세션에서 이 파일을 그대로 붙여넣으면 컨텍스트 잡고 바로 이어서 작업 가능.

---

## 0. 프로젝트 목표

메이플 플래닛 (https://mapleplanet.co.kr) 캐릭터의 보스 단일 타격 데미지를 **단일 숫자(환산 주스탯)** 로 압축해서 비교 가능하게 해주는 웹 사이트를 만든다. 본점 메이플의 maplescouter.com 같은 역할.

**왜 만드나**: 메이플 플래닛 전용 환산 사이트가 검색해도 안 나옴 (빈 자리). 메랜담/메랜Hub/메팁 등은 메이플랜드 전용이고 시스템이 다름. maplescouter는 본점 KMS 6차 전용.

## 1. 메이플 플래닛 게임 정체

- **MSW(메이플스토리 월드)** 위에 만든 **공식** 클래식 RPG
- 컨셉은 "본점 메이플 빅뱅 이전" 무드지만 — 메이플랜드처럼 옛 공식 그대로가 **아님**
- 전직 시스템: **4차까지** (Lv 200 5차 / V매트릭스 / 하이퍼스킬 / 링크스킬 / 유니온 등은 **없음**)
- 본점에서 가져온 현대 시스템들이 들어와 있음:
  - **잠재능력 + 큐브 (수상한 큐브 / 미라클 큐브)** — 등급은 **유니크가 최대** (레전더리 미출시, 단기 출시 계획 없음)
  - **보스 공격 시 데미지% (보스뎀)**
  - **몬스터 방어율 무시% (방무)** — 스우 ≥ 300%, 세렌 ≥ 380%
  - **데미지%, 마력% 잠재 옵션** — 마갤 실측 결과 마력%는 데미지%와 동일하게 작동
  - 펫 자동 시전, 운명의 수레바퀴, 경매장
- 패치 활발 (2026년에도 계속 업데이트). **버전 명시 필수.**

### 메이플랜드와의 차이
| 변수 | 메이플랜드 | 메이플 플래닛 |
|---|---|---|
| 데미지% / 보스뎀% / 방무% 잠재 | ❌ | ✅ |
| 마력% / 공격력% 잠재 | 일부만 | ✅ 완전 적용 |
| 5차 / V매트릭스 | ❌ | ❌ (둘 다 4차까지) |

| 크리티컬 데미지% 옵션 | 직업 자체 스킬뿐 | (현재 미적용 — grade=4 레전더리 옵션이 데이터에만 존재) |

## 2. 데미지 공식

### 마법 공격 (메플플 마갤 실측 검증됨)
```
표기 마력 = (템 마력 + INT) × (1 + 마력% / 100)

기본 데미지 = {(마력² / 1000 + 마력) / 30 + INT / 200} × 스킬공격력
최종 데미지 = 기본 × 엠플 보정 × (1 + 데미지%)
```
**핵심**: 마력%와 데미지%가 **곱연산으로 함께** 들어감.

### 물리 공격 (본점 빅뱅 전 공식 + 잠재 곱연산)
```
표기 공격력 = (템 공격력) × (1 + 공격력% / 100)

max = (주스탯 × 무기상수_max + 부스탯) × 공격력 / 100
min = (주스탯 × 무기상수_min × 0.9 × 마스터리 + 부스탯) × 공격력 / 100

최종 = 기본 × (1 + 데미지%) × (1 + 보스뎀%)            [보스일 때]
     × 크리티컬 기댓값
     × (1 - 보스방어율 × (1 - 방무%₁) × (1 - 방무%₂) × ...)
     × 스킬 데미지%
```

### 무기상수 (구 메이플 기준 — 메플플 자체 조정 가능성 검증 필요)
| 무기 | max | min | 주스탯 | 부스탯 |
|---|---|---|---|---|
| 한손검 | 4.0 | 1.2 | STR | DEX |
| 한손도끼/둔기 | 4.4 | 3.2 | STR | DEX |
| 양손검 | 4.6 | 3.2 | STR | DEX |
| 양손도끼/둔기 | 4.8 | 3.4 | STR | DEX |
| 창/폴암 (서서) | 3.0 | 1.0 | STR | DEX |
| 활 | 3.4 | 1.2 | DEX | STR |
| 석궁 | 3.6 | 1.2 | DEX | STR |
| 단검 | 3.6 | 1.3 | LUK | STR+DEX |
| 표창 | 3.6 | 1.3 | LUK | STR+DEX |

## 3. 환산 주스탯 정의 (메플플 버전, 본점 maplescouter 공식 이식)

```
환산 주스탯 ∝ (주스탯 + 부스탯 / 무기상수)
            × ((템공/마력 × (1 + 공%/마력%)) / 100)
            × (1 + 데미지%)
            × (1 + 보스뎀%)             ← 보스 모드일 때
            × (1 + 총데미지%)           ← (구 "최종 데미지", 패치로 이름 바뀜)
            × ((1.35 + 크뎀%) × 크리율 + (1 - 크리율))    ← 크리티컬 기댓값
            × (1 - 보스PDD × (1 - 방무₁) × (1 - 방무₂) × ...)
            × 평균마스터리보정
```

## 4. 큐브 시스템 (페이지 JS 직접 분석 결과)

### 큐브 종류
- **수상한 큐브 (SUSPICIOUS)** — 일반 큐브
- **미라클 큐브 (MIRACLE)** — 가중치 개선된 상위 큐브 (2026 패치로 옵션 풀 가중치 향상)

### 등급
- 0=노멀, 1=레어, 2=에픽, 3=유니크 ← **현재 게임 내 최대**
- **grade=4 = 레전더리 (미출시).** 데이터에는 옵션이 들어있지만 UI 노출 안 됨, 단기 출시 계획 없음. 환산기에서는 **존재하지 않는 등급으로 처리**.
- 레어→에픽 6.0%, 에픽→유니크 1.8%

### 줄별 등급 분포
- 1줄: 100% 동일 등급
- 2줄: 동일 10% / 한 단계 아래 90%
- 3줄: 동일 1% / 한 단계 아래 99%

### 출현 횟수 제한 옵션
- **3줄 중 최대 1줄까지**: "쓸만한 스킬 계열", "피격 후 무적시간 증가"
- **3줄 중 최대 2줄까지**: "피격 시 일정 확률로 데미지 % 무시", "피격 시 일정 확률로 일정 시간 무적"
- 재계산 확률 = 표기확률 / (100% - 제외된 옵션의 표기확률 합)

### 부위 코드 → 한글 (15개)
```
Weapon=무기, Longcoat=한벌옷, Pants=하의, Coat=상의,
FaceAccessory=얼굴장식, EyeAccessory=눈장식, Earrings=귀고리,
Pendant=펜던트, Belt=벨트, Ring=반지, Cap=모자,
Glove=장갑, Shoes=신발, Shield=방패, Cape=망토
```

### optionType 코드 (페이지 JS의 `canApplyOptionType` 함수)
| 코드 | 적용 부위 |
|---|---|
| 0 | 모든 부위 |
| 10 | 무기 전용 |
| 11 | 무기 제외 |
| 20 | 한벌옷 / 하의 / 상의 |
| 40 | 액세서리 6종 (얼굴·눈·귀·펜던트·벨트·반지) |
| 51 | 모자 전용 |
| 52 | 한벌옷 / 상의 |
| 53 | 한벌옷 / 하의 |
| 54 | 장갑 전용 |
| 55 | 신발 전용 |

### 레벨 인덱스
```js
levelIdx(reqLevel) = clamp(round(reqLevel / 10), 1, 20)
```
옵션 수치는 레벨 10단위 1~20단계 중 하나에서 가져옴.

### 옵션 객체 스키마
```json
{
  "id": 1,
  "grade": 0,
  "weight": 20,
  "optionType": 0,
  "reqLevel": 0,
  "text": "STR : +#incSTR",
  "level": {
    "1": {"incSTR": 1},
    "2": {"incSTR": 1},
    ...,
    "20": {"incSTR": 6}
  }
}
```
- `text` 안의 `#XX` 토큰은 `level[lvIdx][XX]` 값으로 치환

### 확률 계산 (페이지 JS의 `buildLineDist`)
```
줄별 옵션 확률 = (등급분포 가중치 m.f) × (그 등급 풀에서의 weight / sumW)
```

## 6. 아직 안 한 것 / 다음 단계 후보

빠른 우선순위:
1. ~~**옵션 카탈로그 정리**~~ → ✅ 완료 (`data/cube_catalog.json` + 위 표).
2. ~~**grade=4 정체**~~ → ✅ 레전더리 (미출시 확정). 환산기 코드에서 grade ≤ 3 만 다루면 됨.
3. **환산 주스탯 공식 PoC** — 캐릭터 입력 → 환산값 산출 (CLI 먼저, 그 다음 UI)
4. **줄별·부위별 기댓값 시뮬레이터** — 페이지 JS의 `buildLineDist` 그대로 이식한 PoC (큐브 효율 비교용)
5. **무기상수 검증** — 한손검(=4) 은 메랜과 일치 ✓. 나머지 무기 + min/마스터리는 메플플 실측 글 추가 수집 필요
6. **보스별 PDD 데이터** — 자쿰/혼테일/시그너스/스우/세렌 등 메플플 적용 수치 (메랜 monster JSON 의 wdef 는 일반몹 위주 — 보스는 별도)
7. **메플플 vs 메랜 몬스터 차이 실측** — 공통 몹 HP/레벨이 같은지 1~2 마리 인게임 검증 후 데이터 재사용 여부 판단
8. **메플플 직업 리스트** — 본점 빅뱅 전 직업 + 메플플 한정 직업 있는지 마갤/공식 사이트 확인

스택 권장: 정적 사이트 + JS (React/Vue/Svelte 택1, Tailwind, Vercel/Netlify 무료 배포). API 없으니 캐릭터 자동 임포트는 불가, **수동 입력 UI** 정성껏 짤 것.

## 8. 데이터 재추출 방법 (페이지가 바뀐 경우)

브라우저로 https://mapleplanet.co.kr/Cube 페이지 통째로 저장 후, 아래 node 스크립트로 추출:

```js
const fs = require("fs");
const html = fs.readFileSync("페이지.html", "utf8");

function extract(varName) {
  const idx = html.indexOf("var " + varName + " = [");
  if (idx < 0) return null;
  const start = html.indexOf("[", idx);
  let depth = 0, i = start, inStr = false, strCh = "";
  for (; i < html.length; i++) {
    const c = html[i];
    if (inStr) {
      if (c === "\\") { i++; continue; }
      if (c === strCh) inStr = false;
      continue;
    }
    if (c === "\"" || c === "'") { inStr = true; strCh = c; continue; }
    if (c === "[") depth++;
    else if (c === "]") { depth--; if (depth === 0) { i++; break; } }
  }
  return html.slice(start, i);
}

fs.writeFileSync("data/suspicious_cube.json", extract("SUSPICIOUS_DATA"));
fs.writeFileSync("data/miracle_cube.json", extract("MIRACLE_DATA"));
```
